Lorentz Transformations — Interactive Simulations

Browser-runnable simulations companion to the openphysica.org course Special Relativity & Lorentz Transformations. Open any file directly — no build step, no dependencies. Adjust the velocity slider in each to see the effect.

  • 01 — Minkowski Spacetime Diagram

    Two reference frames overlaid in (x, ct). Click anywhere to place an event; the page reports its coordinates in S and S′ via the Lorentz transformation, plus the spacetime interval ds².

  • 02 — Two Light Flashes (Relativity of Simultaneity)

    The classic example: a moving spacecraft flashes light forward and backward simultaneously. In the ship’s frame both detectors fire at the same time; in the ground frame the back one fires first. The speed of light is still c in both frames.

  • 03 — Time Dilation (Light Clock)

    A photon bouncing between two mirrors. In the clock’s rest frame the photon goes straight up and back. In a frame where the clock moves, the photon traces a longer zigzag at speed c — so the tick takes γ times longer.

  • 04 — Length Contraction

    A 1-metre ruler at rest, compared to the same ruler measured in a frame where it moves at v. The moving ruler is shorter by exactly 1/γ.

  • 05 — Relativistic Velocity Addition

    Plot of u = (u′ + v) / (1 + u′v/c²) versus the Galilean u = u′ + v. The relativistic curve stays bounded between −c and +c; light flashed from any moving frame still travels at c.
